# ARBISOFT — Start Here

Read this file first, then read `PROJECT_SPEC.md`, `DESIGN_SYSTEM.md`, `CODEX_INSTRUCTIONS.md`, and `IMPLEMENTATION_PLAN.md`.

Build a premium, mobile-first, static website for an AI, automation, and digital-business studio. The website informs and qualifies prospects; the primary conversion is a WhatsApp conversation. It does not process payments.

The operating flow is: website → WhatsApp scope discussion → agreement → Bonsai client/invoice/payment link → payment through Stripe where supported or an external/offline method such as Wise, Payoneer, IBAN, or bank transfer → delivery and record keeping.

Never invent legal registration details, addresses, testimonials, client logos, case studies, performance claims, or delivery evidence. Owner-specific data must remain configurable until supplied.
