# Implementation plan

## Phase 1 — Foundation

- Install the five source-of-truth documents at repository root.
- Initialize Git, set the GitHub origin, commit, and push when authentication allows.
- Research modern studio patterns, open-source interaction libraries, static deployment, and the Zoho Invoice payment workflow.

## Phase 2 — Experience

- Build a complete mobile-first static site with the four approved services.
- Add anchored navigation, WhatsApp conversion paths, service exploration, process, qualification guidance, About, contact, and policy content.
- Add metadata, favicon, 404, accessibility, reduced motion, and responsive refinements.

## Phase 3 — Operations

- Create `docs/DESIGN_RESEARCH.md`, `BONSAI_SETUP.md`, `PAYMENT_WORKFLOW.md`, `DEPLOY_CLOUDFLARE.md`, `QA_REPORT.md`, and `OWNER_OPERATIONS.md`.
- Verify the site locally and document all owner inputs still required.
- Commit and push the implementation. Deployment/account authorization is completed by the owner when required.
